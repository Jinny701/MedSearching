1. 总体功能描述

本系统融合知识图谱与LLM-RAG技术，通过分析用户药品查询、比较、推荐三类核心需求，构建药品多维度知识图谱，结合优化的检索策略与适配的大语言模型，以本地B/S架构实现精准、个性化的药品信息检索与智能问答，同时保障用药安全。

智能检索

支持自然语言交互，精准回答药品信息，满足用户个性化用药咨询需求。

药品查询

支持通用名、商品名、成分等多维度检索，快速定位药品说明书。

药品比较

多药品结构化对比，辅助用药决策，清晰呈现药物差异。

知识图谱

可视化展示药品关联信息，揭示药物与疾病、症状等复杂关系。

2. 技术特点

系统采用本地化B/S架构，深度融合大语言模型（LLM）、检索增强生成（RAG）与药品领域知识图谱，构建安全、高效、可解释的智能药品说明书检索平台。

2.1 交互层：响应式前端与知识图谱可视化

交互层基于现代Web技术栈构建，采用Vue3作为核心框架，结合Element UI实现标准化、高可用的用户界面组件，提升操作流畅度与用户体验。通过HTML5、CSS3和JavaScript实现跨浏览器兼容与动态交互逻辑。为支持知识图谱的直观展示，引入D3.js进行图结构渲染，实现节点关系的动态布局、缩放、点击展开等交互功能；同时使用Jinja2模板引擎处理动态数据渲染，确保页面内容高效加载与更新。

2.2 通信层：安全高效的HTTP/HTTPS协议传输

通信层采用标准的HTTP/HTTPS协议，实现前后端之间的安全数据交换。所有请求均通过加密通道传输，保障用户查询内容与系统返回结果的隐私性与完整性。

2.3 服务层：Python生态驱动的智能服务引擎

服务层以Python 3.11为核心开发语言，基于Flask框架搭建轻量级Web服务，负责接收前端请求、调用后端逻辑模块并返回结构化响应。集成OpenAI API实现自然语言理解与生成能力，结合RAG流程完成上下文检索与答案生成。

2.4 存储层：多源异构数据统一管理

存储层采用多格式协同架构，以满足不同类型数据的存储需求。其中，Neo4j用于构建和维护药品知识图谱，支持实体（如药品、适应症、不良反应）及其复杂关系的高效存储与图遍历查询；Excel与JSON格式文件用于存储原始药品说明书文本、结构化字段数据及配置信息，便于数据导入和离线处理。

3. 运行环境

5. 系统安装说明

安装Python依赖
确保已安装Python3.11及pip。在项目根目录下（即app.py所在目录），执行以下命令安装所有依赖库：
pip install flask openai numpy scikit-learn jieba pandas py2neo python-Levenshtein
安装并启动数据库
  • 下载并安装Neo4j图数据库（Community或Enterprise版本）
  • 启动Neo4j服务。通常可以通过Neo4j Desktop或命令行启动
  • 配置数据库凭证。访问Neo4j浏览器界面http://localhost:7474/，默认用户名为neo4j。首次启动需要设置密码
  • 在app.py文件中，修改数据库连接信息：
    • graph=Graph('http://localhost:7474/', name='neo4j', password='您的密码')
配置系统参数
  • 数据库连接配置： app.py中直接编码了Neo4j的连接信息，如需修改连接地址或数据库名，请编辑app.py
  • 大语言模型（LLM）配置： app.py中直接编码了LLM的API Key和基础URL，替换为您自己的有效APIKey和LLM服务提供商的正确API端点
初始化系统
  • 确保static/data/目录下存在以下文件：
    • 药品通说明书数据（8803条）.xlsx
    • 药品通数据_知识图谱.csv
    • 医学词典.txt
    • 中医药词表.txt
    • stopwords.txt
  • app.py在启动时会自动执行initial(graph)函数来清空并重建Neo4j知识图谱。注意：这会删除Neo4j中已有的所有节点和关系
运行系统
确保Neo4j数据库服务已启动并可访问。确保LLM API配置正确。在项目根目录下，执行以下命令启动Flask应用：
python app.py
应用默认会在http://127.0.0.1:5000启动。
查看是否安装成功
  • 访问 http://127.0.0.1:5000，如果能看到包含"药品说明书智能检索系统"标题、功能导航栏、AI助手对话框等的页面，说明Flask服务已成功启动
  • 尝试在首页的AI助手对话框中输入问题，如"布洛芬有什么禁忌？"，观察是否有响应返回
  • 尝试点击导航栏中的"药品查询"、"药品比较"等链接，检查页面是否能正常加载
重要提示

首次启动系统前，请确保Neo4j数据库已正确配置并运行，且app.py中的数据库连接参数与您的Neo4j设置匹配。否则系统将无法正常启动。

6. 系统启动

6.1 启动依赖服务

  • Windows： 通过Neo4j Desktop启动，或在命令行运行neo4j.bat console（在Neo4j安装目录下）
  • Linux/macOS： 在终端运行bin/neo4j start(在Neo4j安装目录下)

确认Neo4j在http://localhost:7474可访问，且Bolt端口7687已监听。

图2：Neo4j启动界面示例

6.2 启动系统程序

  • 确保依赖服务已启动，进入系统根目录
  • 执行启动命令：
    • python app.py
  • 如需指定IP和端口，可以修改app.py中的app.run()参数，例如：
    • app.run(host='0.0.0.0', port=8080, debug=True)
  • 启动成功后，根据app.py中app.run()的配置，在浏览器中输入对应的地址(http://127.0.0.1:5000)访问系统

7. 系统具体功能及使用

7.1 智能检索

功能定位： 作为系统的主入口，提供基于大语言模型（LLM）与检索增强生成（RAG）技术的自然语言交互服务。支持用户通过症状描述、用药疑问等自由文本输入，实现个性化药品查询、药品比较以及基于症状的药品匹配推荐，并结合交互式对话捕捉用户个性化需求，提供可视化知识图谱与精准用药参考，助力科学用药。

进入系统首页后，点击顶部导航栏"智能检索"标签页或直接在首页输入框中提问
在输入框中输入自然语言问题，例如"我有糖尿病，喉咙痛可以吃哪些药？""咳嗽发烧吃什么药好？"
点击发送按钮提交请求，系统自动解析用户意图，判断是否为症状查询、药品推荐、药品比较等类型

7.2 药品查询

功能定位： 支持用户通过药品名称（通用名、商品名、别名及模糊名称匹配）快速查找其完整说明书信息，是系统最常用的基础查询功能。

点击顶部导航栏"药品查询"标签页
在搜索框中输入目标药品名称，如"感冒灵颗粒"
点击"搜索"按钮，系统将在本地知识库中进行精确检索或模糊匹配
返回页面展示匹配药品列表，包含功能主治、主要成分、禁忌、指导价等关键字段，点击"详情"按钮，可跳转至完整说明书页面
图7：药品查询功能首页
图8：药品查询结果页面

7.3 药品比较

功能定位： 用户输入需比较的药品名称或相关需求，系统自动识别目标药品，从疗效、安全性、价格、剂型等维度提取关键信息，生成结构化对比报告，清晰呈现各药品优劣与适用场景，助力精准选药。

点击顶部导航栏"药品比较"标签页
在输入框中依次添加需比较的药品名称，如"布洛芬"和"感冒灵"
可点击"+ 添加药品"继续增加对比项，最多支持4个药品同时比较
点击"开始对比"按钮，系统自动提取各药品的核心属性
返回结果页面通过生成结构化对比表格，列明所对比药物在各项属性的差异，包括但不限于：商品名称、英文名称、汉语拼音、指导价、是否为处方药、药物成分、功能主治、用法用量、不良反应、禁忌症、药物相互作用等
图9：药品比较功能首页
图10：药品比较结果页面

7.4 知识图谱

功能定位： 基于药品知识图谱构建的可视化探索工具，揭示药品与其相关实体之间的复杂关联，助力深度理解用药逻辑。

点击顶部导航栏"知识图谱"标签页
页面提供"节点查询"和"关系查询"两种查询模式。其中，节点查询为默认选项，用于查找特定实体及其直接关联；可选关系查询，用于探索特定关系路径
"节点类型"下拉菜单中可选择实体类别，包括药品、成分、适应症、剂型、用法和特殊人群，在"关键词"输入框中输入目标词，如"布洛芬片"
"关系查询"下拉菜单中可选择关系类型，包括使用途径、采用剂型、包含成分、功能主治、忌用人群、禁用人群和慎用人群
点击"查询"按钮，系统将在Neo4j图数据库中执行图遍历查询
查询结果以知识图谱形式展示，中心节点为查询对象，周边节点为其关联实体
